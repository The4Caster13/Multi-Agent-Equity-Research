Feature

Scenario modeling

Move one term and watch every holder's outcome move with it — with the version you started from still on record.

What a scenario carries

A scenario is not a copy of the spreadsheet. It is a set of overrides on the reconciled cap table, so the base never drifts and the diff is always readable.

Term overrides

Change a preference multiple, toggle participation, add a cap, or convert a class — one field at a time, each with its own audit line.

Side-by-side diff

Any two scenarios compare holder by holder. Rows that moved are flagged with the term that moved them, not just the delta.

Signed statements

Publish a scenario and each holder gets a statement they can verify independently — same math, same sources, no spreadsheet attached.

Built for the awkward questions

The ones that arrive at 9pm the night before a board meeting, phrased as "what if."

"What if we take the bridge instead?"

Model the note alongside the priced round. See where the discount and the cap actually bind, and what each does to the common pool at three exit values.

"Does the new pool come before or after?"

Pre-money and post-money pool expansions are separate scenarios, not a footnote. The dilution lands on whoever the term says it lands on.

"Who is actually underwater at $90M?"

Sweep the exit value and the answer comes back as a list of names and a break-even point — with the clause that produced each one attached.

Run your own numbers.

Send us a term sheet and a cap table. We will come back with a reconciled model and three scenarios you did not ask for.
